herdr-dumb はサードパーティのワークフロープラグインをサポートしません。インストール、検出、マニフェスト、アクション、起動・イベントフック、プラグインペイン、リンクハンドラーを削除しました。

既存の登録情報やファイルはディスクに残りますが、読み込まれません。旧プラグイン API は feature_disabled を返し、plugin_action キーバインドは診断付きで無視されます。移行前に既存セッションを完全に停止してください。ライブハンドオフは実行中のプロセスを維持します。組み込みエージェント連携、ローカルコマンド、クリップボード、通常の Web リンクは利用できます。ペイン内のプログラムはサンドボックス化されません。
