---
title: herdr-dumb のインストール
description: 自動更新のないローカル専用フォークをビルドして実行します。
---

[herdr-dumb のリリース](https://github.com/patbonecrusher/herdr-dumb/releases) からビルド済みアーカイブをダウンロードするか、Rust、just、Zig 0.16.0 を用意してこのチェックアウトからビルドします。上流のインストーラーやパッケージは、このフォークではなく元の Herdr をインストールします。

## ダウンロード

- `herdr-dumb-windows-x86_64.zip`: 展開し、`conpty` ディレクトリを `herdr-dumb.exe` と同じ場所に置いたままにします。
- `herdr-dumb-macos-arm64.tar.gz`: 展開して `herdr-dumb` を実行します。

## ビルド

```bash
just build
```

## 実行

```bash
./target/release/herdr-dumb --version
./target/release/herdr-dumb
```

設定とセッションは `herdr-dumb`（デバッグ時は `herdr-dumb-dev`）に分離されます。既存の `herdr` データは移動・削除されません。`HERDR_SOCKET_PATH` と `HERDR_CLIENT_SOCKET_PATH` は引き続き有効なので、別の Herdr セッション内から起動する場合は解除してください。

## 更新

アップデーター、リリースチャンネル切り替え、検出マニフェストのダウンロードはありません。変更する場合は新しいリリースをダウンロードまたはビルドし、実行ファイルを手動で置き換えます。同梱の検出ルールとローカルオーバーライドは利用できます。

## セキュリティ

サードパーティのプラグイン、そのダウンロード、クリップボード画像の転送は削除しました。組み込みエージェント連携、Web リンク、ペイン内プログラムは利用できます。制御には TCP/UDP ではなくローカル IPC を使います。ペイン内プログラムはサンドボックス化されません。
