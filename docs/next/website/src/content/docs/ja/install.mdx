---
title: herdr-dumb のインストール
description: 自動更新のないローカル専用フォークをビルドして実行します。
---

Rust、just、Zig 0.16.0 を用意し、このチェックアウトからビルドします。上流のインストーラーやパッケージは、このフォークではなく元の Herdr をインストールします。

## ビルド

```bash
just build
```

## 実行

```bash
./target/release/herdr-dumb --version
./target/release/herdr-dumb
```

設定とセッションは `herdr-dumb`（デバッグ時は `herdr-dumb-dev`）に分離されます。既存の `herdr` データは移動・削除されません。`HERDR_SOCKET_PATH` と `HERDR_CLIENT_SOCKET_PATH` は引き続き有効なので、別の Herdr セッション内から起動する場合は解除してください。

## 更新

アップデーター、リリースチャンネル切り替え、検出マニフェストのダウンロードはありません。変更する場合は手動でビルドし、実行ファイルを置き換えます。同梱の検出ルールとローカルオーバーライドは利用できます。

## セキュリティ

プラグイン、そのダウンロード、Web リンク、ペイン内のプログラムは利用できます。信頼できるプラグインのみを使用してください。制御は TCP/UDP ではなくローカル IPC を使います。プラグインやペイン内プログラムを隔離するサンドボックスではありません。
