---
title: Install herdr-dumb
description: Build and run the local-only fork without self-updates.
---

Download a prebuilt archive from the [herdr-dumb releases](https://github.com/patbonecrusher/herdr-dumb/releases), or build from this checkout with Rust, just, and Zig 0.16.0 installed. Upstream installers and package-manager releases install the original Herdr, not this fork.

## Download

- `herdr-dumb-windows-x86_64.zip`: extract it and keep the `conpty` directory beside `herdr-dumb.exe`.
- `herdr-dumb-macos-arm64.tar.gz`: extract it and run `herdr-dumb`.

## Build

```bash
just build
```

## Run

```bash
./target/release/herdr-dumb --version
./target/release/herdr-dumb
```

Configuration and saved sessions are isolated under `herdr-dumb` (`herdr-dumb-dev` for debug builds). Existing `herdr` data is not migrated or deleted. Explicit `HERDR_SOCKET_PATH` / `HERDR_CLIENT_SOCKET_PATH` overrides still apply; clear them when launching from another Herdr session.

## Updates

There is no updater, release-channel switch, or detection-manifest downloader. To change versions, download or build a new release and replace the executable manually. Bundled detection rules and local overrides remain available.

## Security

Third-party plugins, plugin downloads, and clipboard image forwarding are removed. Built-in agent integrations, web links, and programs in panes remain available. Herdr uses local IPC, not a TCP/UDP control listener; pane programs are not sandboxed.
