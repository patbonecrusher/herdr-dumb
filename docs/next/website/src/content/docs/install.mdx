---
title: Install herdr-dumb
description: Build and run the local-only fork without self-updates.
---

Build from this checkout with Rust, just, and Zig 0.16.0 installed. Upstream installers and package-manager releases install the original Herdr, not this fork.

## Build

```bash
just build
```

## Run

```bash
./target/release/herdr-dumb --version
./target/release/herdr-dumb
```

Configuration and saved sessions are isolated under `herdr-dumb` (`herdr-dumb-dev` for debug builds). Existing `herdr` data is not migrated or deleted. Explicit `HERDR_SOCKET_PATH` / `HERDR_CLIENT_SOCKET_PATH` overrides still apply; clear them when launching from another Herdr session.

## Updates

There is no updater, release-channel switch, or detection-manifest downloader. To change versions, build and replace the executable manually. Bundled detection rules and local overrides remain available.

## Security

Plugins, plugin downloads, web links, and programs in panes remain enabled. Only install plugins you trust. Herdr uses local IPC, not a TCP/UDP control listener; it is not a sandbox for plugins or pane programs.
