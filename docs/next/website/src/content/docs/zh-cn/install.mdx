---
title: 安装 herdr-dumb
description: 构建并运行没有自更新的本地专用分支。
---

安装 Rust、just 和 Zig 0.16.0 后，从此工作副本构建。上游安装器和包管理器安装的是原版 Herdr，而不是此分支。

## 构建

```bash
just build
```

## 运行

```bash
./target/release/herdr-dumb --version
./target/release/herdr-dumb
```

配置和会话保存在独立的 `herdr-dumb` 目录中（调试构建为 `herdr-dumb-dev`）。不会迁移或删除原有 `herdr` 数据。`HERDR_SOCKET_PATH` 和 `HERDR_CLIENT_SOCKET_PATH` 仍可覆盖默认路径；从其他 Herdr 会话启动时请清除这些变量。

## 更新

没有更新器、发布通道切换或检测清单下载。需要更换版本时，请手动构建并替换可执行文件。内置检测规则和本地覆盖仍然可用。

## 安全

保留插件、插件下载、网页链接和窗格内程序。仅安装可信的插件。控制接口使用本地 IPC，而不是 TCP/UDP 监听器；这不是用于隔离插件或窗格内程序的沙箱。
