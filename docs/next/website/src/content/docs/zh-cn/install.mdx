---
title: 安装 herdr-dumb
description: 构建并运行没有自更新的本地专用分支。
---

从 [herdr-dumb 发布页](https://github.com/patbonecrusher/herdr-dumb/releases) 下载预构建归档，或安装 Rust、just 和 Zig 0.16.0 后从此工作副本构建。上游安装器和包管理器安装的是原版 Herdr，而不是此分支。

## 下载

- `herdr-dumb-windows-x86_64.zip`：解压后保持 `conpty` 目录与 `herdr-dumb.exe` 位于同一位置。
- `herdr-dumb-macos-arm64.tar.gz`：解压后运行 `herdr-dumb`。

## 构建

```bash
just build
```

## 运行

```bash
./target/release/herdr-dumb --version
./target/release/herdr-dumb
```

配置和会话保存在独立的 `herdr-dumb` 目录中（调试构建为 `herdr-dumb-dev`）。不会迁移或删除原有 `herdr` 数据。`HERDR_SOCKET_PATH` 和 `HERDR_CLIENT_SOCKET_PATH` 仍可覆盖默认路径；从其他 Herdr 会话启动时请清除这些变量。

## 更新

没有更新器、发布通道切换或检测清单下载。需要更换版本时，请下载或构建新版本并手动替换可执行文件。内置检测规则和本地覆盖仍然可用。

## 安全

第三方插件、插件下载和剪贴板图像转发已移除。内置智能体集成、网页链接和窗格内程序仍可使用。控制接口使用本地 IPC，而不是 TCP/UDP 监听器；窗格内程序不受沙箱隔离。
