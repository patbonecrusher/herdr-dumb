herdr-dumb 不支持第三方工作流插件。安装、发现、清单、动作、启动和事件钩子、插件窗格以及链接处理器均已移除。

已有插件注册信息和文件保留在磁盘上，但不会加载。旧插件 API 返回 feature_disabled；plugin_action 快捷键会被忽略并给出诊断。切换版本前请完全停止已有会话：实时交接会保留正在运行的进程。内置智能体集成、本地命令、剪贴板和普通网页链接仍可使用。窗格内程序不受沙箱隔离。
