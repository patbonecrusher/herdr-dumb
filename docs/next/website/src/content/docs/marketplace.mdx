Third-party workflow plugins are not supported in herdr-dumb. Installation, discovery, manifests, actions, startup/event hooks, plugin panes, and link handlers have been removed.

Existing plugin registries and files are left on disk but never loaded. Legacy plugin API requests return feature_disabled; plugin_action keybindings are ignored with a diagnostic. Fully stop existing sessions before switching builds: live handoff preserves already-running processes. Built-in coding-agent integrations, local commands, clipboard, and ordinary web links remain available. Programs launched in panes are not sandboxed.
